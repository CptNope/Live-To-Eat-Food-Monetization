## How it works

`index.html` is the public-facing research summary. `live-to-eat-food-research-brief.html` is a synchronized alternative filename. `reports.html` loads and formats the three original Markdown files directly from this repository, with a per-report table of contents, access to the original Markdown, and a print-to-PDF option. It uses externally hosted Marked and DOMPurify scripts for Markdown rendering and sanitization. If these scripts are unavailable, the complete plain-text Markdown is displayed instead.

The research contains experimental prices, model assumptions, conflicting audience estimates and source references that may not work outside the originating AI session. Verify first-party audience data, laws, financial calculations and contracts before commercial use. The proposed website revenue split is not an agreement. The v2 design is linked as a pending concept and is not part of this repository.
